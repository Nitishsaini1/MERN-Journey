🧠 Concepts Learned

Integer = whole number (no decimal part).

Math.floor() automatically converts numeric strings into numbers.

JavaScript performs implicit type conversion (type coercion).

NaN means Not a Number and appears when JavaScript cannot convert a value into a valid number.

Number() converts strings into numbers.

Number.isInteger() checks whether a value is a whole number.

Input values from HTML are always strings.

User input should never be trusted without validation.

🐞 Debugging Lessons

Today I found several logic mistakes by reasoning through the code.

I learned to:

Read every if statement like an English sentence.

Test the code mentally using valid and invalid inputs.

Check whether the action inside the if matches the condition.

Convert the input before validating it.


Instead of guessing, I now know how to debug logic step by step.
